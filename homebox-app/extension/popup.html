Open an AI chat

Open a new chat, then click the round Homebox button at the bottom right. Using another site? Open it and enable Homebox from the Home tab.

How it works

  1. Open an AI chat site in a new chat.
  2. Click the round Homebox button on the page (or press Alt+Shift+H).
  3. Type what you want in box 1 and click Start task. Homebox keeps going by itself until the AI says DONE.
  4. Approve or deny each change. The AI says DONE when finished.

Common problems

The AI just gives me code

Start a new chat and use the Homebox button → Start task instead of typing into the chat box.

Results didn't send

They're in the chat's message box. Press Send yourself, or use Put in chat box in the page panel.

"App isn't running"

Start Homebox on this computer. This popup updates by itself.

Changed a permission?

Start a new chat so the AI learns its new tool list.
