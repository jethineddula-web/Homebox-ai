Welcome

Let AI from any chat website work in one folder on your computer and in your apps. You decide what it may do.

How Homebox works

  1. 1. Pick a folderThe AI can only see and change files inside your AI folder.
  2. 2. Ask on an AI chat siteOpen ChatGPT, Claude or Gemini, click the round Homebox button at the bottom right, and type your task there.
  3. 3. Approve the changesHomebox shows each change first. Click Approve, then see the result in your folder.

    AI folder

    The AI can only see and change files in the active folder (also called the sandbox). Use a project folder, never your whole user folder.

    Add pictures or files

    Put files into the active AI folder so the AI can use them, for example photos for a website or a reference picture for a 3D model. Pictures go into pictures, other files into files. You can also add pictures from the Homebox panel on the chat page.

    Connect an AI

    Pick the way that fits your AI. The browser extension is the easiest.

    Install once

    1. and unzip it (or use the homebox-extension folder that came with Homebox).
    2. Open chrome://extensions (Edge: edge://extensions) and turn on Developer mode.
    3. Click Load unpacked and choose the homebox-extension folder.
    4. Click the Homebox icon in the toolbar, then Connect. Approve the code that appears here.
    Download extension

    Connected browsers

    Then, on any AI chat site

    Open a new chat, click the round Homebox button at the bottom right, type your task and click Start task. Using another site? Open it and click Enable in the extension popup.

    Check the site's rules first. Each AI site has its own terms, and some don't allow their website to be used through tools like this extension. Only use Homebox on sites whose terms allow it. AI apps with MCP support, such as Claude Desktop, are an officially supported way to connect (turn on Show advanced options in Settings to see MCP apps).

    Full access
    AI runs everything you turned on below without asking you first: file changes, commands, Maya and other apps. Things set to Off stay off. Typing, clicking and emails in your browser still ask you every time. Pause still stops everything.
