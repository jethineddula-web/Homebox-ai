Glossary

Short, plain explanations of the words you'll meet when using Homebox and AI tools.

Action block (homebox block)
A fenced code block marked homebox in which the AI writes what it wants to do, for example write_file index.html followed by the file's content. Homebox finds these blocks on the chat page, runs them (with your approval) and sends the results back.
Approval
A request from the AI to do something that changes your computer. Homebox shows the full content or code first; you approve or deny. Ignored requests are denied after five minutes.
Auto-run
The switch called Let the AI keep working by itself in the Homebox panel on the chat page. When on (the default), Homebox runs the AI's action blocks as soon as the answer is finished and sends the results back automatically.
Bridge
A small Homebox script that runs inside an app such as Maya, Blender or Houdini, so Homebox can send it steps. It only accepts connections from your own computer, and only with Homebox's secret key.
ExtendScript
Adobe's scripting language for Photoshop, Illustrator and After Effects. It's an older version of JavaScript, so modern features like arrow functions don't work.
Full access
A Homebox setting that lets the AI run everything you've allowed without asking first. Things set to Off stay off, and Pause still stops everything. See Approvals or Full access.
Localhost (127.0.0.1)
The network address that means "this computer". Homebox only listens on it, so other devices and the internet can't reach it.
MCP (Model Context Protocol)
An open standard that lets AI apps use tools. Apps such as Claude Desktop, Cursor and VS Code can connect to Homebox's private MCP link and use its tools without the browser extension.
Pairing
Connecting a browser to Homebox. The extension shows a four-digit code, and you approve the same code in Homebox. Only paired browsers can send actions.
Pause
The emergency stop in Homebox's sidebar. It cuts off all AI access at once and denies anything waiting, until you resume.
Prompt injection
Instructions hidden in text the AI reads, such as a file or web page, that try to make it do something you didn't ask for. See Prompt injection explained.
Sandbox folder
The one folder the AI may work in. File tools can't reach anything outside it, and secret files inside it stay hidden.
Starter prompt
The instructions Homebox sends the AI with your first task: how to write action blocks, which tools it may use and the rules to follow. The Homebox button sends it for you.
Undo
Homebox backs up files before the AI changes or deletes them; the Undo button on the Activity page restores them. Inside 3D apps, each AI step is also one normal undo step.
VSIX
The package format for VS Code extensions. Homebox builds its VS Code extension as a VSIX and installs it with VS Code's own installer.
Homebox

Let AI from any chat website work in one folder on your computer and in your creative apps. You stay in control of every step.
