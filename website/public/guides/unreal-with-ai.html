Block out a level in Unreal Engine with AI

By Jethin · 1 October 2026 · 2 min read

A blockout is the rough first version of a level: simple shapes that show layout, scale and flow before any real art exists. It's repetitive work, which makes it a good job for AI. The Unreal Editor can be scripted in Python, and Homebox lets an AI chat send that Python, step by step, with your approval.

Set up Unreal (once per project)

  1. Enable PythonIn the Unreal Editor choose Edit → Plugins, search for Python Editor Script Plugin, enable it and restart the editor.
  2. Turn on Unreal in HomeboxOpen Apps → Unreal Engine and switch on Let AI control Unreal Engine.
  3. Start the bridgeOpen Window → Output Log, switch the Cmd drop-down to Python, paste the setup line from Homebox and press Enter. The log prints Homebox: Unreal Engine is listening on port 7015.
  4. Optional: start it with the projectIn Edit → Project Settings → Plugins → Python, add the bridge file path shown in Homebox under Startup Scripts.

Ask for a blockout

In Unreal, block out a small courtyard using the engine's basic
shapes (/Engine/BasicShapes/Cube): a 20 m x 20 m floor, walls 4 m
high on three sides with a 3 m gap on the fourth, two 1 m pillars
near the gap, and a point light 6 m above the centre. Use
centimetres, label every actor clearly (Blockout_Floor,
Blockout_Wall_N …) and put them in a folder called Blockout.
Report each actor's location and scale.

A typical step spawns a few actors through the editor subsystem:

actors = unreal.get_editor_subsystem(unreal.EditorActorSubsystem)
cube = unreal.EditorAssetLibrary.load_asset('/Engine/BasicShapes/Cube')
floor = actors.spawn_actor_from_object(cube, unreal.Vector(0, 0, 0))
floor.set_actor_scale3d(unreal.Vector(20, 20, 0.1))
floor.set_actor_label('Blockout_Floor')
floor.set_folder_path('Blockout')
print(floor.get_actor_label(), floor.get_actor_location())

Each approved step runs inside one editor transaction, so Ctrl+Z in Unreal removes the whole step.

Working with scale

Unreal uses centimetres, and the basic cube is 100 units across. Most blockout mistakes are scale mistakes, so ask the AI to report locations and scales after each step. Then you can say "the walls overlap the floor edge by 50 cm, move them in" and it can fix it precisely.

Ideas to try next

  • "Add a PlayerStart at the courtyard entrance, facing inwards."
  • "Duplicate the courtyard 3 times along X with 5 m gaps, as a street."
  • "Give all Blockout actors a simple grey material instance so they read clearly."
  • "List every actor in the Blockout folder with its bounds."

Troubleshooting

  • No "Python" in the Cmd drop-down: the Python Editor Script Plugin isn't enabled yet.
  • Works in one project but not another: the plugin and startup script are set per project.
  • The editor stalls on a step: very large spawns can take time. Ask for fewer actors per step.

More prompts to try

  • "Add a simple staircase of 10 steps leading to a 3 m high platform on the north wall."
  • "Place five point lights in a row along the courtyard with a warm colour."
  • "Snap every Blockout actor to a 50 cm grid and report anything that moved."
  • "Delete all actors in the Blockout folder except the floor. (Check the approval before you approve this one.)"
