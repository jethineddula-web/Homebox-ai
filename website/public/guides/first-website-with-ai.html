Build your first website with AI

By Jethin · 30 September 2026 · 3 min read

This guide takes you from an empty folder to a small website you can open in your browser. You won't write any code. You'll describe what you want, watch the AI create the files, and ask for changes in plain English.

Before you start

  • Homebox is running and your browser is connected (the extension icon shows Connected). If not, follow the install steps.
  • You have an account on an AI chat site. ChatGPT, Claude and Gemini all work well for this.

1. Make a fresh folder

In the Homebox window, open Folders, type a path such as C:\Users\you\Documents\my-first-site, tick Create if missing and click Add. The new folder becomes the active sandbox. A clean folder makes it easy to see exactly what the AI creates.

2. Start the task

Open your AI site in a new chat, click the round Homebox button and type something like:

Build a small website for a neighbourhood bakery called "Crumb & Co".
Pages: home, menu, about, contact. Share one style.css.
Warm colours, big photos (use placeholder images), and a menu
with prices. It must work by opening index.html directly.

Press Start task. Homebox sends your request together with the instructions the AI needs.

3. Watch the steps

The AI usually starts by looking at the folder (list_dir), then writes files one at a time. Each write_file step shows up for approval in the Homebox panel and in the Homebox window, with the full file content. Skim it and click Approve. With Let the AI keep working by itself switched on (the default), Homebox sends each result straight back and the AI moves on.

Want it hands-free? Turn on Full access in the Homebox sidebar. The AI will write the files without stopping. Turn it off again when the task is finished.

4. Open your site

When the AI says DONE, click Open sandbox folder on the Homebox home screen and double-click index.html. Your site opens in the browser.

5. Improve it

Keep chatting in the same conversation. Good follow-ups are specific:

  • "Make the header stick to the top and shrink when scrolling."
  • "The menu prices don't line up. Use a two-column layout."
  • "Add a dark mode that follows the computer's setting."

The AI reads its earlier files, edits only what's needed and reports back. If you don't like a change, open Activity and click Undo next to it.

Common hiccups

  • The AI pasted code instead of creating files. You typed into the chat directly. Use the Homebox button → Start task in a new chat.
  • It stopped after a few steps. Reply "Continue with homebox blocks until the site is finished."
  • Images are missing. The AI can't download images. Ask it to use placeholder services, or drop your own photos into the folder and tell it their names.

What's next

Make it yours

Once the basics work, add your own material. Copy your photos into an images folder in the sandbox, then ask: "Use the photos in the images folder on the menu page, with short captions." The AI can see the file names, so naming them clearly (croissant.jpg rather than IMG_2041.jpg) gives better results.
