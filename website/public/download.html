Download Homebox

Free for Windows 10 and Windows 11. One installer with the Homebox app; the browser extension for Chrome, Edge, Brave and Opera is inside it.

Download for Windows

Version 2.0 · 64-bit · about 110 MB

Install in four steps

  1. Run the installerOpen Homebox-Setup-2.0.0.exe and follow the steps. If Windows shows "Windows protected your PC", click More info → Run anyway. This appears for new apps until they build up a reputation with Microsoft.
  2. Open HomeboxUse the desktop shortcut. A short tour shows you around, and the What to do now card always shows your next step. Closing the window keeps Homebox in the tray; right-click the tray icon to quit.
  3. Add the browser extensionIn Homebox open Connect AI → Download extension and unzip it. Then open chrome://extensions (Edge: edge://extensions), turn on Developer mode, click Load unpacked and choose the homebox-extension folder.
  4. ConnectClick the Homebox icon in your browser toolbar, then Connect. A four-digit code appears. Click Approve next to the same code in Homebox.

That's it. Next: give the AI its first task.

Is it safe to install?

Homebox installs for your Windows account only, without administrator rights. It doesn't add drivers or system services and doesn't change system settings. It listens only on 127.0.0.1, so other computers on your network and websites cannot reach it. Quit it from the tray and all AI access stops. Read more on the safety page.

Uninstall

Use Settings → Apps → Installed apps → Homebox → Uninstall in Windows, and remove the extension from your browser's extensions page. Your settings and activity log stay in the .homebox folder in your user folder; delete it to remove everything. If you turned on automatic start for Maya or other apps, turn it off in Homebox first.
