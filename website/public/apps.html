How app connections stay safe

For 3D apps, Homebox uses a tiny bridge script that runs inside the app. It only accepts connections from your own computer, and only with a secret key that Homebox keeps in your user folder. Adobe and Office apps are reached through Windows' own automation system, and only while they are open. OBS uses its built-in, password-protected WebSocket server.

App scripts are real code and can reach outside the sandbox folder. That's why each app starts turned off and each step asks for approval by default. Read more about safety.
