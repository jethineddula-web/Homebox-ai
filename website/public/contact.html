Before you write

Many answers are in the how-to guide, FAQ and troubleshooting pages.

Reporting a problem

Please include:

  • Your Windows version and browser
  • Which AI chat site or app you were using
  • What you expected and what happened instead
  • Any error message, and the matching line from the Activity page

Please don't send passwords, API keys or private files.

Security reports

If you've found a way around Homebox's limits, email us with "Security" in the subject line. Please give us a reasonable time to fix it before sharing it publicly.
