Automate Excel with AI

{{articleMeta}}

Homebox connects to the Excel window you already have open. The AI writes short PowerShell scripts that use Excel's own automation interface, so it can read cells, write formulas, format ranges and add charts, exactly as if you'd done it by hand.

Save first. Excel cannot undo changes made by scripts. Save your workbook (or work on a copy) before letting AI change it.

1. Turn on Excel

  1. Open your workbook in Excel.
  2. In Homebox, go to Apps → Excel, turn on Let AI control Excel and click Test connection. It should show Excel's version.
  3. Start a new chat so the AI learns about the Excel tool.

2. Let the AI look first

Good results start with the AI understanding your data. Ask:

In Excel, look at the active sheet: list the column headers,
the number of rows, and 5 sample rows. Don't change anything yet.

3. Clean and calculate

Now give it the job, with clear rules:

Clean the sheet: trim spaces in column B, make dates in column C
real dates, remove fully empty rows. Then add column F "Total"
= Quantity * Price as a formula, formatted as currency.

Each step shows its script for approval. Scripts use $excel, which Homebox connects to your open Excel, for example $ws.Range("F2").Formula = "=D2*E2". Formulas are better than pasted values, because they keep working when data changes.

4. Build a summary

Add a new sheet "Summary" with total sales per month and per
product using SUMIFS, and a clustered column chart of monthly totals.

Word and PowerPoint work the same way

Turn on Word or PowerPoint in Homebox → Apps. The AI gets $word or $ppt. In Word, each AI step is one Undo. In PowerPoint, save first, as with Excel.

Troubleshooting

  • "Excel is not open": open the workbook, then approve the step again.
  • "Could not reach Excel": a cell is probably in edit mode or a dialog is open. Press Esc in Excel and retry.
  • Formulas show as text: ask the AI to set .Formula rather than .Value2 for those cells.

Formulas the AI uses most

It helps to recognise the formulas you'll see in the approval cards:

FormulaWhat it does
SUMIFSAdds up values that match one or more conditions, such as all sales for one product in one month.
XLOOKUPFinds a value in one column and returns the matching value from another. It's the modern replacement for VLOOKUP.
IFERRORShows something friendlier, such as a blank, when a formula would give an error.
TEXTFormats numbers and dates as text, for example TEXT(A2,"mmm yyyy").
UNIQUE / SORTBuilds a list of distinct values, sorted, which is handy for summary tables.

If a formula looks unfamiliar, ask the AI: "Explain the formula in F2 in plain words." Understanding the formulas means you can trust, and fix, the sheet later.

More prompts to try

  • "Highlight every row where the total is above 1,000 in light green."
  • "Add a column with the month name from the date in column C."
  • "Find duplicate customer names and list them on a new sheet. Don't delete anything."
  • "Freeze the header row and make the columns fit their contents."
