Fix code errors in VS Code with AI

{{articleMeta}}

Most AI coding help still happens in a chat window: you paste an error, the AI suggests a fix, you copy it back, run it, and repeat. With Homebox and its small VS Code extension, the AI can look at the same errors you see in VS Code, change the files itself and open them for you. You stay in charge: every change is shown before it happens, and anything can be undone.

What the AI can and can't see

The Homebox extension for VS Code gives the AI four things it normally lacks:

  • Your active file and selection, so you can say "fix the function I've selected".
  • Which files have unsaved changes. The AI is told never to overwrite those, and to ask you to save first.
  • The Problems panel: the same errors and warnings VS Code shows you, with file, line and message.
  • A way to open a file at a line, so it can show you what it changed.

It only ever reports files inside your sandbox folder. If another project is open in a different window, the AI sees nothing from it, not even the file names.

1. Set it up once

  1. Turn on VS Code in HomeboxOpen Apps → VS Code and switch on Let AI control VS Code.
  2. Install the extensionSwitch on Install the Homebox extension in VS Code. Homebox uses VS Code's own installer, so there's nothing to download separately.
  3. Reload VS CodeClose and reopen VS Code, or run Developer: Reload Window from the Command Palette (Ctrl+Shift+P). A Homebox item appears in the status bar at the bottom right.
  4. Make your project the sandboxOpen your project folder, click the Homebox item in the status bar and choose Use this folder as the AI sandbox. The item then says AI works here.

2. Ask for a fix

Start a new chat on your AI site, click the round Homebox button and give a task like this:

Look at the errors VS Code shows in this project and fix them.
Don't change behaviour, only fix the errors. After each change,
check the Problems panel again. When there are no errors left,
open the main file you changed.

A typical session goes like this:

  1. The AI calls vscode_info and vscode_problems to see where the errors are.
  2. It reads the files involved with read_file.
  3. It fixes them with edit_file, which replaces an exact piece of text. You see the old and new text side by side before approving.
  4. It checks vscode_problems again. If new errors appear, it keeps going.
  5. Finally it calls vscode_open, and the changed file opens in VS Code at the right line.

3. Adding and deleting files

The AI can create new files with write_file and remove old ones with delete_path. Deleting is deliberately careful:

  • Homebox makes a full backup first, so Undo on the Activity page brings the file or folder back exactly.
  • It refuses to delete the whole sandbox, folders that contain protected files (such as .env or keys), and anything too large to back up.
  • Like any change, a delete waits for your approval unless you've turned on Full access.

4. Working on several projects

Every VS Code window shows Homebox in its status bar. The window the AI works in says AI works here; the others say Use this folder. Click it to move the AI to that project. Folders you've used before switch without asking again. Start a new chat when you switch, so the AI doesn't mix up two projects.

Tips for better fixes

  • Save before you start. Unsaved edits in VS Code and changes on disk can conflict.
  • Use Git. Committing before a big AI session gives you a second safety net on top of Homebox's Undo. See Undo, backups and Git.
  • Be specific about scope. "Only change files in src/api" keeps the AI focused.
  • Ask for tests. If you allow commands, "run the tests and fix failures before saying DONE" catches mistakes early.

Troubleshooting

  • "VS Code is not connected": reload VS Code after installing, and check that the Homebox item is in the status bar.
  • Homebox is missing in one window: reload that window. Homebox also works in Restricted Mode, in folders you haven't marked as trusted.
  • "Sandbox folder not open there": VS Code is connected but has a different folder open. Click Use this folder in the window you want.
