What's new

Release notes for Homebox. Updates are announced here first.

Version 2.0

{{lastUpdated}}

New

  • A new control panel with a "What to do now" card, a guided tour, search (Ctrl+K) and keyboard shortcuts.
  • 17 apps: Maya, Blender, Houdini, 3ds Max, Cinema 4D, Nuke, Unreal Engine, Substance 3D Painter, Photoshop, Illustrator, After Effects, Excel, Word, PowerPoint, AutoCAD, OBS Studio and VS Code, each with step-by-step setup.
  • VS Code support: the AI sees your open files, selection and Problems panel, and opens the files it changed. Each VS Code window shows whether the AI works there, and one click switches projects.
  • Delete with Undo: the AI can delete files and folders, and every delete is fully backed up first.
  • Full access: an optional switch that lets the AI work without asking, with a clear banner while it's on.
  • Desktop app and installer with a tray icon and approval notifications.
  • Auto-run on by default in the chat-page panel, plus a shortcut (Alt+Shift+H) to show or hide it.

Security

  • Maya now uses Homebox's secure bridge, which needs a secret key, instead of Maya's open command port.
  • The control panel can't be shown inside other websites, which protects against tricks that make you click buttons without knowing.
  • Extra protection against Windows file-name tricks that could reveal hidden secret files.
  • Approvals always show the complete code; overly long code is refused instead of shortened.

Fixes

  • The Arena "Battle mode" check no longer triggers on other chat sites.
  • Connecting a browser no longer fails if you take a while to approve the code.
  • Buttons and pages respond faster.

Version 1.0

First release: the browser extension, a sandbox folder with approvals and Undo, paste mode, MCP support and Maya.
