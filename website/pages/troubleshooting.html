Troubleshooting

Most problems have a quick fix. Find what you see below.

What you seeWhat to do
The extension says "Homebox app is not running"Open Homebox from the Start menu or desktop shortcut. It keeps running in the tray when you close its window. The popup updates by itself within a second or two.
Homebox opens in the browser instead of its own windowAnother copy of Homebox is already running (for example an older version). Quit it from its tray icon or Settings → Quit, then open Homebox again. Only one Homebox can run at a time.
The AI gives you a script instead of doing the workStart a new chat and use the round Homebox button → Start task. If it still happens, reply: "Don't give me a script. Use homebox blocks, as in my first message."
The AI's actions aren't picked upThey must be in ```homebox code blocks. Ask the AI to use them. You can also press Run next to a step in the Homebox panel.
The same action appears again and againThe results didn't reach the chat. Click Put in chat box in the Homebox panel and press Send.
Results are in the message box but not sentPress Send yourself. Some chat sites change their buttons often.
Arena shows two answers side by sideThat's Battle mode. Pick Run (left) or Run (right), or use Direct Chat for full auto-run.
The AI says it doesn't have a tool (for example maya_run_python)That app or permission is off. Turn it on in Homebox, then start a new chat.
An app says "not reachable"Open the app with no dialog box waiting. For 3D apps, the Homebox bridge must be running inside the app: paste the setup line from Homebox → Apps, or turn on Start automatically and restart the app.
"Maya did not answer in time"Close any open dialog in Maya. Check the Script Editor for "Homebox: Maya is listening on port 7017". If Maya was just restarted, run the setup line again or turn on automatic start.
After Effects doesn't answerTurn on Edit → Preferences → Scripting & Expressions → Allow Scripts to Write Files and Access Network.
OBS says the password is wrongIn OBS, open Tools → WebSocket Server Settings → Show Connect Info, and copy the password into Homebox → Apps → OBS Studio.
A chat site changed its design and something brokeUse the Copy and Put in chat box buttons, or paste mode on Connect AI, which works with any AI.
Buttons in the extension don't respondAfter updating Homebox, reload the extension on chrome://extensions and refresh the chat page.

Still stuck? Contact us and include what you tried and any error message. The Activity page and .homebox\audit.jsonl show exactly what happened.
